# Personal Task Manager — Product Summary

**Vision:** To give individuals a calm, focused space to see all their goals clearly and think deeply about how to accomplish them — without the noise of team tools, automations, or cloud dependencies.

**Target Audience:** Polymaths and generalists who work across many domains and need a single place to manage all goals with depth, not just checklists.

**Core Features:**
- Grid-based task overview with visual card layout
- Task detail view with subtasks and dependencies
- AI-assisted chat per task (thinking partner, not autonomous manager)
- Priority and status management
- Local-first storage with no cloud dependency
